# Mushukistan Cookie Policy

Version: 2026-10-30

The verified Android app does not use cookies.

The app stores the access token in platform secure storage.

The verified web app does not intentionally set advertising, analytics, or tracking cookies. The web app may use browser storage through the Flutter secure storage integration to keep the user's access token for authentication. It also stores a random viewer identifier used only to count each visitor once in post view counts.
