# Mushukent Monorepo Skeleton

This repository now contains a production-ready project skeleton for MVP implementation.

## Top-level layout
- `backend/` FastAPI + SQLAlchemy + Alembic skeleton
- `frontend/` Flutter + Riverpod + GoRouter skeleton
- `docs/` canonical architecture/product documentation
- `infrastructure/` Nginx config and deployment docs
- `.github/` CI workflow
- `docker-compose.yml` local orchestration for backend + PostgreSQL/PostGIS + Nginx

## Status
- Architecture and implementation skeleton complete.
- Business features are intentionally not implemented yet.
